# Water Tracker Widget

A simple Flutter app that helps users track how many glasses of water they drink each day.

## Features

* Add a glass of water.
* Track progress towards a daily goal of 8 glasses.
* Reset the counter.

## Three Main Attributes

* **Glasses:** Number of glasses consumed.
* **Daily Goal:** Target of 8 glasses.
* **Progress:** Shows how close the user is to reaching the goal.

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome`.
